# Blockery workbench

This directory tracks pack and deployment work using the
[`todo-manager`](https://github.com/jd-santos/Skills/tree/main/skills/todo-manager)
workflow. Runtime worlds, private settings, and server backups stay outside it.

- [TODO.md](TODO.md) lists current priorities from P1: Rush through P5: Minor.
- [work/](work/) holds detailed checklists and decisions for substantial efforts.
- [DONE.md](DONE.md) points to history and retained evidence, not a completed-task ledger.
